# Intro

What the project is and how its files are described. Read it before anything else.

| Folder | What it holds |
| --- | --- |
| `Brief/` | The project brief: the user, the problem, Marco's motivation, the focus and the scope |
| `Metadata/` | The metadata schema: the block every file starts with and its allowed values, including the tags |

- Start from `Brief/brief.md`, then the questions in `../01_Research/Questions/initial_questions.md`.
- Open `Metadata/metadata_schema.md` when you create or tag a file; `CLAUDE.md` imports it.
