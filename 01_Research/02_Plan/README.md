# Plan

The research plan and the instructions for running it, with the record of where the work stands.

| File | What it is | Read it when |
| --- | --- | --- |
| `01_plan.md` | The activities A1 to A8, their goals, sources, outputs, order of work and "done when" checks | Before starting or choosing an activity |
| `02_desk_research_instructions.md` | How the agent runs the desk research: scope, principles, evidence rules, output template, source files, grading, candidate lists | At the start of every desk research session; read the sections you need |
| `03_progress.md` | Running record of the desk research, for resuming work in a new session | First, at the start of every session; its old log lines keep the paths of the time |
| `04_open_issues.md` | Open questions, weak sources and contradictions, each with a priority and a criticality | Before deciding what to check or ask next |

- `03_progress.md` is long: read "Current state" and "Next step", not the whole log.
- The activity outputs (`01_…` to `08_…`) are saved in `01_Research/`, not here.
