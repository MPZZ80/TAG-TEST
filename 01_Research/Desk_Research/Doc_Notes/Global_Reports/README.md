# Global Reports: index of sources

Read this file instead of opening every source file. It lists the 56 sources of this category (GR-001 to GR-056), last regenerated on 2026-10-07 after the complete reading.

- **What is here:** Official statistics and reports from institutions, regulators, industry bodies, operators and consultancies. One file per: report, dataset or official page.
- **Note:** Grades are provisional: citations are not counted yet. Sources in German, French, Dutch, Spanish, Japanese and Korean carry working translations.
- **Text copies** are in `../../docs_md/Global_Reports/` and downloaded documents in `../../docs/Global_Reports/`, with the same base name as the source file. Both folders are kept out of Git.

## How to use it

1. Find the sources you need in the table, by topic, geography or grade.
2. Open only those source files: each has who produced the source, when, how, its grade with the points, what it says, the data already extracted with page numbers, and its limits.
3. For more detail, search the text copy by keyword. Do not read a text copy from start to finish: some are close to a million characters.
4. Check every figure against the original document or live page before citing it.
