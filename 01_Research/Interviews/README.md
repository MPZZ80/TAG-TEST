# Interviews

The interviews with commuters: recordings, automatic transcripts and one notes file per interview.

## Read in this order

1. The notes files in this folder. Each one gives the journey leg by leg, what the participant does when something goes wrong, how they find out, what they would change, and the agent's reading against the findings of `../desk_research_partial_analysis.md`.
2. A transcript in `_Transcripts/`, only to check a quote or a doubt listed at the end of a notes file.

Do not read the transcripts from start to finish to find something: they are automatic, in Italian and full of errors. Search them.

## What is in this folder

| Item | What it is |
| --- | --- |
| `<name>_notes.md` | Notes on one interview, written by the agent. Same base name as its transcript; an interview recorded in several parts has one notes file |
| `_Transcripts/` | Automatic transcripts of the recordings, in Italian, one per recording. Marco's files: they have no metadata block and are not edited |
| `_raw/` | The recordings |
