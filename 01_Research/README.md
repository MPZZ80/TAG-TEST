# Research

Everything about the research: the plan, the working rules, the state of the work and the sources. The folders are numbered in the order they were created, and so are the files inside them that had no number of their own.

## Read in this order

1. **`02_Plan/03_progress.md`**: where the work stands and what the next step is. Read it at the start of every session and update it as you work.
2. **`02_Plan/01_plan.md`**: the activities A1 to A8, what each must produce, and the three phases (desk research, Marco's review, interviews).
3. **`02_Plan/02_desk_research_instructions.md`**: how to do the desk research. Read the sections you need: 3 scope, 5 evidence rules, 7 output template, 11 source files and documents, 12 grading, 13 candidate lists.
4. **`03_Desk_Research/Doc_Notes/README.md`**: the map of the sources. Go from there to the index of one category, and only then to single source files.

## What is in this folder

| Folder | What it is |
| --- | --- |
| `01_Questions/` | The 40 research questions, Q1–Q40, and the prompt that generated them; see its `README.md` |
| `02_Plan/` | The plan, the desk research instructions, the progress record and the open issues; see its `README.md` |
| `03_Desk_Research/Doc_Notes/` | One file per source, in six category folders, each with an index in its `README.md` |
| `03_Desk_Research/docs/` | Documents downloaded from the sources, by category. Not in Git |
| `03_Desk_Research/docs_md/` | Text copies in Markdown of the documents and web pages, by category. Not in Git |
| `04_Interviews/` | The interview script, recordings, automatic transcripts and one notes file per interview; start from its `README.md` |
| `05_Survey/` | The commuter survey in six languages, where to post it, the script that builds the forms, the answers and the results; start from its `README.md` |

The analyses built on the research (touchpoints, features, user stories) are in `../02_Analysis/`, outside this folder.

`desk_research_partial_analysis.md`, which this guide used to list, is no longer in the repository.

## To save reading

- Do not open the source files one by one: use the category indexes.
- Do not read a text copy in `03_Desk_Research/docs_md/` from start to finish; search it by keyword. Some are close to a million characters.
- `03_Desk_Research/docs/` and `03_Desk_Research/docs_md/` exist only on Marco's computer. In a fresh clone they are missing and must be downloaded again from the links in the source files.
