# Survey Responses

The answers to the commuter survey, exported from Google Forms. One file per language form.

| File | What it is |
| --- | --- |
| `survey_en.csv`, `survey_it.csv`, `survey_de.csv`, `survey_fr.csv`, `survey_nl.csv`, `survey_es.csv` | The responses of each form, exported as CSV, unchanged |

- **How to export:** open the form in edit mode, tab "Risposte" / "Responses", menu with three dots, "Scarica risposte (.csv)" / "Download responses (.csv)". Rename the file as above.
- **Do not edit the CSV files.** They are the raw data; any cleaning or counting goes in a separate file.
- **Kept out of Git** by `.gitignore`: the answers are anonymous, but the two open questions may contain details that identify someone.
- Export again to replace a file when new answers arrive; the analysis must say the export date.
