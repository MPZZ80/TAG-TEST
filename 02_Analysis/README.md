# Analysis

Analyses built on top of the research notes.

| File | What it is |
| --- | --- |
| `01_research.html` | The research as one offline web page, opened by double-click: a home page that lists the sections (touchpoints, features, user stories, interviews, survey, desk research, plan and method), one section shown at a time, and one search over all of them. Touchpoints, features, interviews and desk research open on their contradictions |
| `02_Generated_Touchpoints.md` | 109 moments of the commute found in the notes and transcripts, as direct, indirect or missed interactions, with phase, mode and the quotes behind each; then 9 contradictions, coverage gaps and counts |
| `03_Generated_Features.md` | 26 features (2 marked [value not traced]), the minimum set that answers the touchpoints, each with the touchpoints it answers, its evidence, [strong] or [weak], and its impact (how many touchpoints it answers); then the features dropped and why |
| `04_Generated_User_Stories.md` | 24 user stories, one per feature with a traced value, each with its source line, under short persona names; the two features sent back and the two splits |
| `05_Human_Touchpoints(not_complete).md` | Marco's own touchpoints, not complete; no metadata block |
| `01_Touchpoints/` | One file per touchpoint, TP-001 to TP-109, split from `02_Generated_Touchpoints.md`; see its `README.md` |
| `02_Features/` | One file per feature, F-01 to F-24 with the splits, split from `03_Generated_Features.md`; see its `README.md` |
| `03_User_Stories/` | One file per user story, US-F-01 to US-F-24, split from `04_Generated_User_Stories.md`; see its `README.md` |
| `Prompts/` | The prompts that generated the files above, numbered like the file each one generates; see its `README.md` |

- Read `02_Generated_Touchpoints.md` by phase: the table is ordered from planning to disruption.
- Each row links to the notes it rests on; open a note only to check a quote.
- Read `03_Generated_Features.md` after the touchpoints: it is ordered by impact.
- Read `04_Generated_User_Stories.md` last: each story names its feature.
