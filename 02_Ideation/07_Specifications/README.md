# Specifications

The specifications built from the user stories, the stories of the chosen concept first, one file per behaviour, technology-agnostic, each usable as a prompt for integration.

| File | What it is |
| --- | --- |
| `Spec_instructions.md` | Instructions, independent of this project, for writing specifications from user stories: inputs, steps, rules, file names and the templates of the foundation, of a specification and of the overview. Ask an agent to "use `Spec_instructions.md` to create the specifications" |
