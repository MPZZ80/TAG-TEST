# Prompts

Example prompts from the course (Lesson 05, Ideation Lab), one for each step of the ideation. They keep the course's own names and numbers and their own metadata block, which does not follow the project schema.

| File | Step |
| --- | --- |
| `prompt-01-hmw.md` | Generate the How-Might-We questions |
| `prompt-03-ideation.md` | Expand the concepts |
| `prompt-04-clustering.md` | Cluster the concepts |
| `prompt-05-prioritisation.md` | Mark the concepts |
| `prompt-06-concept.md` | Draft the concept document |

- Open one only to see how a step of the ideation was framed; the files of `02_Ideation/` say what came out of it.
- Course material: do not edit.
