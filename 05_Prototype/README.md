# Prototype

The frontend-only prototype of the product: interface, flows and interactions, in plain HTML, CSS and JavaScript, with mock data. No backend, no API, no server.

| Folder | What it is |
| --- | --- |
| `instructions/` | The rules for building the prototype. Read `Prototype_Instructions.md` first |
| `html/` | Six screens; `index.html` is the entry point |
| `css/` | `style.css`, a placeholder until Marco provides the real style |
| `js/` | One script per screen, plus `common.js` |
| `data/` | Seven mock datasets every content comes from, one commented file each |
| `assets/` | Images, icons and fonts. Empty for now |

- Open `html/index.html` in a browser; no server is needed.
- Use the prototype controls at the bottom of each screen to switch scenario: on time, late, past the limit, cancelled, no news.
