# Prototype Screens

One HTML file per screen; `index.html` is the entry point. Each file loads the style, the data files it needs, `../js/common.js` and its own script.

| File | Screen | Page | Specification |
| --- | --- | --- | --- |
| `index.html` | The list of the screens built so far, for review | — | — |
| `run.html` | The real state of the run; `?run=ID` chooses the run, `?scenario=` the scenario | PG-02 Run | SPEC-02 |

- Screens are built one specification at a time, from `../../04_Specifications/`. Links to screens not built yet show as plain text.
