# HTML

One HTML file per screen, structure only; the content comes from `../data/`. Each file names in its first comment the specifications it shows. Every screen shows the scenario picked in the prototype controls (`?scenario=<id>`).

| File | Screen | Specifications |
| --- | --- | --- |
| `index.html` | Today: the usual trip at a glance, with one answer to act on. Entry point | SPEC-05, SPEC-02, SPEC-04 |
| `trip.html` | Today's trip in detail: legs, facts with source and age, travellers' reports, report in one step, the connection ahead | SPEC-02, SPEC-03, SPEC-08 |
| `ways_out.html` | Ways out when the trip breaks, side by side, chosen only with the commuter's yes | SPEC-06 |
| `contacts.html` | Those waiting are told: the message ready to send, contacts who have and have not accepted | SPEC-07 |
| `plan.html` | Every way door to door, side by side, for a planned day | SPEC-09 |
| `alerts.html` | When to tell the commuter: days, moments, channels, kinds of event, and what would be sent now | SPEC-04 |

- Not shown yet: SPEC-10 to SPEC-17.
