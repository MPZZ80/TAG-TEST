# Prototype Scripts

One script per screen, with the same name as its HTML file, plus `common.js`.

| File | What it does |
| --- | --- |
| `common.js` | Shared by every screen: scenario from the URL query, interface texts, header with the scenario selector and the mock clock, simulated messages, facts with source and age, what is missing and where to set it up |
| `alerts.js` | Fills the screen: alerts on the usual trip (SPEC-04) |
| `claim.js` | Fills the screen: compensation from the trip (SPEC-13) |
| `connection.js` | Fills the screen: the connection ahead (SPEC-08) |
| `contacts.js` | Fills the screen: those waiting are told (SPEC-07) |
| `drive.js` | Fills the screen: the route stays with the driver (SPEC-16) |
| `fare.js` | Fills the screen: the fare that fits the days (SPEC-12) |
| `index.js` | Fills the screen: index of the screens (SPEC-02 to SPEC-17) |
| `run.js` | Fills the screen: the real state of the run (SPEC-03) |
| `sessions.js` | Fills the screen: sessions still running (SPEC-17) |
| `setup.js` | Fills the screen: set-up (SPEC-02) |
| `station.js` | Fills the screen: the station ahead (SPEC-14) |
| `stop.js` | Fills the screen: the stop approaching (SPEC-15) |
| `tickets.js` | Fills the screen: tickets (SPEC-11) |
| `timing.js` | Fills the screen: times that can be kept (SPEC-10) |
| `today.js` | Fills the screen: today's trip (SPEC-05, SPEC-03, SPEC-08) |
| `ways.js` | Fills the screen: every way door to door (SPEC-09) |
| `ways_out.js` | Fills the screen: ways out when the trip breaks (SPEC-06) |
