## Decisions taken

- **Desk personas.** The prompt asks for a persona from the interviews. Only 21 features are lived by an interviewee; for the others the person comes from the desk note and is marked. Set aside: forcing an interview persona onto a moment that person never described, which would invent the circumstance.
- **What counts as a traced value.** A "so that" is kept when the note states an outcome the person seeks or protects (a seat, not being fined, getting home, knowing in time). It is not kept when the only outcome would be the feature working, which restates the capability.
- **No new capability.** Where a source asks for more than the feature (automatic compensation in [OR-013](../Desk_Research/Doc_Notes/Online_Reviews/OR-013_apple-app-store_2026_sncf-connect-fr.md), a sign on the bus in [OF-002](../Desk_Research/Doc_Notes/Online_Forums/OF-002_eisenbahnforum_2016_eisenbahnforum-reiseerlebnisse-bahn.md)), the story keeps the feature's own line.
