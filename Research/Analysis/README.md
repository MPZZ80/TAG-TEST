# Analysis

Analyses built on top of the research notes.

| File | What it is |
| --- | --- |
| `Generated_Touchpoints.md` | Every moment of the commute found in the notes, as direct, indirect or missed interactions, with phase, mode and the quote behind each; then contradictions, coverage gaps and counts |
| `Generated_Features.md` | 73 features proposed for the touchpoints (13 marked [value not traced]), each marked [strong] or [weak] by the evidence behind its touchpoint, with the features dropped and why |
| `Generated_User_Stories.md` | 60 user stories, one per feature with a traced value, each with its source line; the features sent back and why |
| `research.html` | The research as one offline web page: the three analysis tables, then every file listed in `Index.md` in full, cross-linked, with a search field. Generated from the Markdown files; open it in a browser, do not edit it |
| `Generated_Research_Report.md` | Marco's file, empty for now |
| `Generated_Reaearch_Report_Prompt.md` | The prompt for the research report (Marco's file) |
| `Generated_User_Stories_Prompt.md` | The prompt for the user stories (Marco's file) |
| `Generated_Features_Prompt.md` | The prompt for the features (Marco's file) |
| `Generated_Touchpoint_Prompt.md` | The prompt used to generate the touchpoints (Marco's file) |
| `Touchpoint.md` | Marco's file |

- Read `Generated_Touchpoints.md` by phase: the table is ordered from planning to disruption.
- Each row links to the notes it rests on; open a note only to check a quote.
- Read `Generated_Features.md` after the touchpoints: each feature names the touchpoints it answers.
- Read `Generated_User_Stories.md` last: each story names its feature.
