# Analysis

Analyses built on top of the research notes.

| File | What it is |
| --- | --- |
| `Generated_Touchpoints.md` | 109 moments of the commute found in the notes and transcripts, as direct, indirect or missed interactions, with phase, mode and the quotes behind each; then 9 contradictions, coverage gaps and counts |
| `Generated_Features.md` | 26 features (2 marked [value not traced]), the minimum set that answers the touchpoints, each with the touchpoints it answers, its evidence, [strong] or [weak], and its impact (how many touchpoints it answers); then the features dropped and why |
| `Generated_User_Stories.md` | 24 user stories, one per feature with a traced value, each with its source line; the two features sent back and the two splits |

- Read `Generated_Touchpoints.md` by phase: the table is ordered from planning to disruption.
- Each row links to the notes it rests on; open a note only to check a quote.
- Read `Generated_Features.md` after the touchpoints: it is ordered by impact.
- Read `Generated_User_Stories.md` last: each story names its feature.
