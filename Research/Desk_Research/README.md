# Desk Research

Everything the desk research collected, in three folders.

| Folder | What it holds | In Git |
| --- | --- | --- |
| `Doc_Notes/` | One synthesis note per source, written by the agent from the documents: what the source says, the evidence with page numbers, its grade and limits, and its links to other notes. Start from its `README.md` | Yes |
| `docs/` | The original documents downloaded from the sources (PDF, data files) | No: they belong to their publishers |
| `docs_md/` | Automatic Markdown conversions of the documents and text captures of web pages, same base name as the note | No |

- To find a source, go to `Doc_Notes/README.md` and then to the index of one category; do not open the notes one by one.
- Do not read a text copy in `docs_md/` from start to finish: search it. Check every figure against the original in `docs/` before citing it.
- In a fresh clone `docs/` and `docs_md/` are missing; the links to download them again are in the notes.
