# Academic Papers: index of sources

Read this file instead of opening every source file. It lists the 28 sources of this category (AP-001 to AP-028), last regenerated on 2026-10-07 after the complete reading.

- **What is here:** Peer-reviewed papers and reviews, found with OpenAlex. One file per: paper.
- **Note:** Only 8 papers have a downloaded PDF; for the other 20 the source file holds the abstract only (publishers block automated downloads). Citation counts come from OpenAlex.
- **Text copies** are in `../../docs_md/Academic_Papers/` and downloaded documents in `../../docs/Academic_Papers/`, with the same base name as the source file. Both folders are kept out of Git.

## How to use it

1. Find the sources you need in the table, by topic, geography or grade.
2. Open only those source files: each has who produced the source, when, how, its grade with the points, what it says, the data already extracted with page numbers, and its limits.
3. For more detail, search the text copy by keyword. Do not read a text copy from start to finish: some are close to a million characters.
4. Check every figure against the original document or live page before citing it.
