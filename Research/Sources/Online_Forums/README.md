# Online Forums: index of sources

Read this file instead of opening every source file. It lists the 4 sources of this category (OF-001 to OF-004), last regenerated on 2026-10-07 after the complete reading.

- **What is here:** Forum and community threads. One file per: thread.
- **Note:** The weakest category: Reddit and most forums block automated reading. Captures may contain forum nicknames; never copy them into other files.
- **Text copies** are in `../../docs_md/Online_Forums/` and downloaded documents in `../../docs/Online_Forums/`, with the same base name as the source file. Both folders are kept out of Git.

## How to use it

1. Find the sources you need in the table, by topic, geography or grade.
2. Open only those source files: each has who produced the source, when, how, its grade with the points, what it says, the data already extracted with page numbers, and its limits.
3. For more detail, search the text copy by keyword. Do not read a text copy from start to finish: some are close to a million characters.
4. Check every figure against the original document or live page before citing it.
