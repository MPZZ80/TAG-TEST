# Online Reviews: index of sources

Read this file instead of opening every source file. It lists the 17 sources of this category (OR-001 to OR-017), last regenerated on 2026-10-07 after the complete reading.

- **What is here:** Samples of user reviews from the Apple App Store. One file per: product and store (a sample of reviews, not one review).
- **Note:** Each file is a sample of the most recent Apple App Store reviews for one app in one country. Not coded yet. Reviewer names are never recorded.
- **Text copies** are in `../../docs_md/Online_Reviews/` and downloaded documents in `../../docs/Online_Reviews/`, with the same base name as the source file. Both folders are kept out of Git.

## How to use it

1. Find the sources you need in the table, by topic, geography or grade.
2. Open only those source files: each has who produced the source, when, how, its grade with the points, what it says, the data already extracted with page numbers, and its limits.
3. For more detail, search the text copy by keyword. Do not read a text copy from start to finish: some are close to a million characters.
4. Check every figure against the original document or live page before citing it.

## Other files in this folder
